# 세법/노무 도우미 — 제품 기획 정책 (코드 확정 기준)

코드에 반영·확정된 제품 기획 정책 모음. 출처는 저장소 코드 주석 및 PRD 참조 ID.

## 답변 유형 3종

- **간단답변**(`isSimpleResponse`): 제목 + 불릿 구조, 근거 법령 칩. 단순 질문에 노출.
- **상세답변**(`isEnhancedResponse`): 인라인 문서형. 섹션 순서는 사실관계 → 질의내용 → 검토내용 → 결론 → 근거법령 → 해석례 → 판례 → AI 상세의견.
- **멀티턴 답변**(`isMultiTurnResponse`): 대화형 줄글(서식 없는 3단 흐름: 결론 → 근거·판례 → 실무 조치) + 하단 법령 링크.
- 최초 답변은 질문 복잡도로 분류하고, 후속 질문(멀티턴)은 **항상 멀티턴 답변**으로 출력한다 (CHA-008: n-2/n 상세답변 강제 전환 없음).

## 멀티턴 횟수 정책 (PRD CHA-004)

- 멀티턴(후속 질문) 횟수는 **3회** (최초 질문 미포함, `MAX_QUESTIONS = 4`). 초과 시 세션 전환 모달 노출.
- 간단답변에서 "상세 답변 받기"로 받은 상세답변(`isDetailUpgrade`)은 **멀티턴 횟수에 포함하지 않는다**.
- 가드레일 차단 질문(부적절 질문)은 거부 메시지를 내되 **세션은 유지하고 횟수에서 제외**한다 (PRD RIS-001, CHA-004). 거부 후에도 잔여 횟수로 멀티턴 지속 가능.

## 플로팅 버튼 정책 (확정 2026-07-03 · PRD CHA-008 §3)

- 채팅 하단 플로팅 버튼 라벨 분기: 최초 간단답변 → **"상세 답변 받기"** / 최초 상세답변·AI 의견 반영 후 → **"의견서 작성"**.
- 의견서 작성으로 세션 종료 시 플로팅 버튼 미노출. **의견서 작성 진입점은 각 상세답변 카드의 버튼으로 단일화** — 상세답변이 n개일 때 어떤 답변 기준인지 모호해지는 문제 + 오조작 시 세션 종료 비용 때문.
- 나가기 확인 모달에도 의견서 작성 버튼을 두지 않는다 (같은 이유).
- 주제 선택 바텀시트가 열려 있으면(접힘 상태 포함) 플로팅 "상세 답변 받기"는 중복이므로 미노출.
- 색상: 플로팅/의견서 버튼은 토스 블루 `#3182F6` 전용 (primary 인디고와 혼용 금지).

## 의견서 작성 플로우 (CHA-008)

- 멀티턴을 수행한 세션: 주제 선택 **바텀시트** 노출 (제안 주제 2개 + 기타 1개).
- 단일 턴 세션: 바텀시트 없이 — 최초 상세답변이면 바로 의견서 작성, 최초 간단답변이면 바로 상세답변 전환.
- 답변별 의견서 작성: 해당 상세답변을 기준으로 의견서를 작성한다 (정책 리뷰 2026-07-03).
- 라이브 세션에서 의견서 작성 시 세션 종료(정책 확정 2026-07-03), 이력 보기(읽기 전용)에서는 문서만 생성.

## AI 상세의견 / AI 의견 요약

- 상세답변 하단에 **AI 상세의견** 진입 카드(그라데이션) → 토론 오버레이(페르소나 2인 × 2라운드).
- 페르소나 고정: **AI 엄격한 법률학자 = 파랑**, **AI 실무형 분석가 = 보라** (혼용 금지).
- "반영하기" 시 답변에 AI 의견 요약 2카드(법률학자/분석가) + 하단 고지 노출. `aiOpinionSummary`는 항상 객체형(pro/con)이어야 2카드로 렌더된다.
- 이력 보기(읽기 전용)에서는 AI 상세의견 카드를 노출하지 않는다 (상호작용 방지).

## 출처(법령/사규) 노출 정책

- 멀티턴 답변 하단 출처 링크에서 **사규는 노출하지 않는다** (사규 인용은 본문에서만).

## 서비스 평가(피드백) 정책 (CHA-012)

- 답변 완료 상태에서 세션 종료 시에만 평가 모달 노출.
- 체험판(trial)에서는 답변 평가 미제공.
- 빈도 게이팅: 대화 세션 **3회당 1회**, 하루 **최대 1회**.
- 문항: 긍정 5 / 부정 4 문항.
- **우선순위: 규정등록 배너 > 피드백 팝업** — 메인 진입 시 규정등록 넛지 배너가 뜰 예정이면 피드백 팝업은 노출하지 않는다.

## 규정(사규) 등록 / 정책 관리

- 미등록 사용자 넛지: 홈 배너로 정책 문서 관리 진입 유도 (`policy-register-inline-cta`). 배너는 dismiss 가능.
- 관리자는 정책 관리 화면에서 등록 완료된 정책의 임베딩 교정(embedding correction) 화면으로 진입 가능. 정책 저장 완료 시 pending 카운트 감소.
- 미등록 힌트 초개인화: 직전 노무 질문 요약 타이틀을 힌트에 노출 (커밋 62189ef).

## 세션 종료/이탈 확인

- 채팅 중(메시지 존재) 다른 화면으로 이동 시 나가기 확인 모달 노출.
- 이력 보기: 채팅 이력 선택 시 이전 대화를 전체 화면으로 읽기 전용 복원.
