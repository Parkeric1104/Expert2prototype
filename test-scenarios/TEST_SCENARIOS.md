## 0. 답변 형태 규칙 (CHA-008 요약 — 판정 기준)

| 구분 | 트리거 | 기대 답변 형태 | 출처 |
|---|---|---|---|
| **간단 답변** | 최초 질문, 복잡도 **낮음**(짧고 단순) | 제목 + 불릿/짧은 본문 | 하단 법령 칩 |
| **상세 답변** | 최초 질문, 복잡도 **중간~높음** | **구조화**: 사실관계 · 질의내용 · 검토내용 · 결론 + AI 의견 요약 | 법령·해석례(하이퍼링크), **사규는 인용만·출처 미노출** |
| **멀티턴 답변** | 후속 질문(2턴~) | **서식 없는 대화형 줄글** | 하단 출처(질문 성격별로 법령/해석례/판례/사규/탐색없음) |

**기능 버튼 — 1개 동적 CTA 버튼 스펙 (UI 리팩토링 반영)**
> `[상세 답변 받기]`·`[의견서 작성]`을 상황에 따라 라벨·동작이 바뀌는 **단일 CTA**로 통합.
> (AI 페르소나 토론 `[AI 상세의견]`은 상세 답변 하단의 **보조 액션**으로 별도 유지 → §3-5)

| 답변 상태 | CTA 라벨 | 동작 |
|---|---|---|
| 간단 답변 | **[상세 답변 생성]** | 클릭 → 상세 답변 생성 |
| 스트리밍 중 | **[생성 중...]** (Disabled) | 클릭 방지 |
| 멀티턴 답변 후 | **[상세 답변 생성]** | 조건1(복수 맥락)→주제 선택 모달→백그라운드 우측 패널 스트리밍→**의견서 바텀시트** / 조건2(단일)→즉시 상세 |
| 상세 답변 후 | **[의견서 작성]** | 의견서 바텀시트 슬라이드업 |
| 멀티턴 5회 초과 | **[최종 의견서 발행]** (Strong Active) | 입력창 비활성이어도 버튼 유지 → 바텀시트로 이탈 방어 |

**멀티턴 카운트(CHA-004)**: 최대 **5회**(최초 미포함). 카운트 제외 = ①최초 ②가드레일 에러 턴 ③간단→상세 변환. 도메인 라우팅 변경 불가.

> ✳ **표기 안내**: 단일 CTA 스펙 및 신규 §3-1-B·3-9·3-10은 **리팩토링/신규 목표 UX 스펙**입니다. 현재 프로토타입 빌드와 차이가 있을 수 있으며, 해당 기능 구현 완료 시점 기준으로 검증합니다.

| — | **[의견서 작성]** | ONEFFICE 의견서 | — | 4단 구조 + 관련 법령, ECM(ONEFFICE) 이관 |

**턴 카운트 계산 (CHA-004)**: `Q2~Q6 = 멀티턴 5회(한도)` / `Q1(최초)·Q2-1~Q6-1(상세받기) = 카운트 제외`.
→ **상세받기를 5번 눌러도 잔여 5회가 유지되는지** 필수 확인.

**핵심 검증 규칙**
1. `[상세 답변 받기]`는 **직전 답변이 멀티턴일 때만** 노출(CHA-008). 상세를 받은 직후 CTA는 `[의견서 작성]`으로 전환 → 다시 멀티턴하려면 대화 **재개 동작**이 필요.
2. 같은 버튼이라도 **Q2-1(단일 맥락)=즉시 상세 / Q5-1(맥락 누적)=주제 선택 팝업**(조건1/조건2 분기).
3. 상세받기로 받은 상세답변은 **5회 카운트 제외**(CHA-004 ③).
4. `Q5(사규)`는 **사규가 등록된 세션**에서만 유효(체험판·미등록 시 스킵).

> **커버리지 목표**: S1~S10 × (Q1 + Q2~Q6 멀티턴 5 + Q2-1~Q6-1 상세받기 5 + AI의견 + 의견서) = **주제 10 × 약 13스텝**.

| 공통 | 가드레일 차단 턴 | **세션 유지 + 횟수 미차감**, 재질문 가능 |

### 3-4. 멀티턴 최대 횟수 (CHA-004 — 5회 제한)
| 턴 | 동작 | 기대 |
|---|---|---|
| 최초 | 상세 질문 | 카운트 0 |
| 1~5회 | 후속 질문 5회 | 각 1 카운트, 잔여 표시 감소 |
| 6회 시도 | 추가 질문 | **한도 초과 안내(세션 한도 모달)** / **입력창 비활성화** |
| **CTA 상태** | 5회 소진 시점 | CTA가 **[최종 의견서 발행]**(Strong Active)으로 변경되어 **퍼널 이탈 방어**, 클릭 시 의견서 바텀시트 |
| 확인 | 중간에 가드레일/라우팅 에러 턴 | **카운트 제외**(잔여 보존) |

### 3-5. AI 상세의견(페르소나 토론) — CHA-005
| 동작 | 기대 |
|---|---|
| 상세 답변 하단 `[AI 상세의견]` | **법률학자(파랑)·분석가(보라)** 토론 → 반영/미반영 선택 |
| 반영 | 상세 답변에 AI 의견 요약 인라인 노출 |
| 노출 조건 | **상세 답변 하단에만**(멀티턴/간단 답변엔 없음) |

### 3-6. 휴먼피드백 (CHA-007)
| 상황 | 기대 |
|---|---|
| 최초 질문이 **상세**로 분류 | 답변 전 **휴먼피드백 게이트**(계속 진행하기 / 질문 수정·추천질문) |
| 최초 질문이 **간단** | 휴먼피드백 미노출, 즉시 답변 |
| **멀티턴** 질문 | 휴먼피드백 미적용 |

### 3-7. 최종 의견서 (CHA-009)
| 동작 | 기대 |
|---|---|
| 상세 답변 하단 `[의견서 작성]`(또는 멀티턴 후 상세받기→의견서) | **ONEFFICE 의견서**: 문서번호·검토유형·작성일 + 질의 + 회신 + 1.사실관계 2.질의 3.검토 4.결론 + 관련 법령·판례 + 고지문 |
| 저장 | 저장유형 선택(ONEFFICE / PDF / Word) |
| 히스토리 | 완료 답변은 이력 저장, 세션 이탈 시 미저장(CHA-011) |

### 3-8. 답변 평가 (CHA-012)
| 상황 | 기대 |
|---|---|
| 답변(상세/간단) 완료 후 세션 이탈 | **답변 평가** 노출(👍/👎 등), KPI 대시보드 집계 |

### 3-9. ✳ 멀티턴 답변 길이 & 사이드 패널 이관 (UX 가이드라인 — 신규)

| TC | 상황 | 기대 |

| TC | 상황 | 기대 |
|---|---|---|

## 4. 데이터 탐색 · 출처 규칙 검증 (DAT-005, CHA-006/008)

| 항목 | 기대 |
|---|---|
| 탐색 우선순위 | **법령 > 판례 > 사규** (법령 최우선) |
| 상세 답변 출처 | 법령·해석례 하이퍼링크, **사규는 본문 인용만·출처 목록 미노출** |
| 멀티턴 출처 | 질문 성격별 노출(법령/해석례/판례/사규/탐색없음) — §2 템플릿 |
| 법령 선택 | 특정 법령 선택 시 그 안에서만 탐색, 미선택+사규선택=전체법령+사규 (CHA-002) |
| 세법/노무 중복선택 | **불가**(CHA-002) |

## 5. 실행 체크리스트 (요약)

- [ ] 최초 질문 복잡도별 **간단/상세** 정확 분기 (§1)
- [ ] 상세 답변 **4단 구조 + AI 의견 요약** 노출
- [ ] 멀티턴 5회 **대화 맥락 유지**(대명사·생략 지시어 해석) (§2)
- [ ] 멀티턴 **출처 종류 전환**(해석례→법령→판례→사규→탐색없음)
- [ ] ✳ **단일 CTA 생명주기** (상세 답변 생성→생성 중→의견서 작성→최종 의견서 발행) (§0, §3-1-B)
- [ ] ✳ 복수 맥락 → **주제 선택 모달 → 백그라운드 스트리밍 → 의견서 바텀시트 슬라이드업** (TC 1-3)
- [ ] 라우팅 가드 **친절화 문구 + [새 채팅 시작하기]** 버튼·신규 세션 생성 (§3-2)
- [ ] 가드레일 차단/통과 6종 (§3-3, 회귀 포함)
- [ ] 멀티턴 5회 한도 + 카운트 제외 3종 + **[최종 의견서 발행] 이탈 방어** (§3-4)
- [ ] ✳ 멀티턴 답변 **300~500자 압축**(서론 삭제) / 상세는 **사이드 패널 800~1,200자 이관** (§3-9)
- [ ] ✳ **계산기 연동**: 채팅 내 [계산기 열기] 칩 → 결과 **의견서 표 자동 주입** (§3-10)
- [ ] AI 상세의견 토론 / 휴먼피드백 / 의견서 / 답변 평가 (§3-5~8)
