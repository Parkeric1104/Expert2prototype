# 기본 동작 (#1) — Q2 이후 확장 테스트 케이스 (QA)

> 기준: `260803_테스트 시나리오.pdf` #1 기본 동작 / PRD(CHA-001·002·004·005·008·009·011·012, DAT-005, RIS-001).
> 목적: 최초 답변(Q1) 이후 **후속(멀티턴) 질문·동작**을 QA 관점에서 방대하게 검증.

## 공통 전제 (별도 명시 없으면 적용)
- **기준 세션 A**: Q1 = **S1**("취업규칙 제14조는 1년, 내 근로계약서는 1년 3개월 — 어느 게 우선?") → **상세 답변** 완료.
- **사규 등록됨**(더존비즈온 취업규칙/인사규정), **route = 노무(EXPERT2)**, 법령 미선택(전체 탐색).
- 별도 세션이 필요한 경우 케이스에 명시(예: 간단답변 세션, 세법 세션, 사규 미등록 세션).

## 판정 기준(공통)
- **PASS**: 기대 답변 형태·출처·동작이 규칙과 일치 + 콘솔/렌더 오류 없음.
- **FAIL**: 형태 오분류 / 출처 규칙 위반 / 맥락 소실 / 카운트 오작동 / 오차단·오허용 / 렌더 깨짐.
- **표기**: `카운트±` = 멀티턴 5회 카운트 반영 여부. ✳ = 리팩토링/신규 목표 스펙(구현 시 검증).
